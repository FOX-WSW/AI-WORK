# 家居制造项目交付助手样板

## 项目背景

项目团队的调研纪要、功能设计、问题记录和代码入口分散在不同成员手中。新成员需要反复询问实施顾问和开发人员，才能确认资料位置、业务边界和功能入口。

首期机器人面向业务顾问、IT 和开发人员，提供脱敏项目资料问答及代码只读检索。机器人只整理事实、证据和待确认项，不替代业务负责人确认需求，也不执行生产写入、发布、权限调整或自动知识启用。

## 首期验收

1. 能登记本地项目资料并保留来源指纹。
2. 能建立项目总览、资料地图、环境地图、代码检索图和权限角色地图。
3. 能生成默认只读的机器人安全起步项目。
4. 能明确区分“脚手架已生成”和“真实机器人已上线”。
